# Кабинет клиента Интерсофт — мобильное PWA

Личный кабинет сопровождения 1С в виде Progressive Web App: открывается на телефоне,
устанавливается на главный экран и работает как обычное приложение.

**Приложение:** https://danya257.github.io/plpk-cabinet/

## Установка на телефон

1. Открой ссылку в браузере телефона (Chrome / Safari).
2. Android (Chrome): меню ⋮ → **«Добавить на главный экран»** (или всплывающее «Установить приложение»).
   iPhone (Safari): «Поделиться» → **«На экран "Домой"»**.
3. Иконка «Интерсофт» появится на главном экране — запускается в полноэкранном режиме.

## Возможности

- Вход по учётным данным клиента ПЛПК (выдаёт менеджер сопровождения)
- Дашборд: персональный менеджер, состояние сопровождения, график обращений
- Обращения: лента, карточка с ходом работ и перепиской, дополнение, создание нового
- Релизы 1С под конфигурацию клиента, документы (счета/акты)
- Вопрос к ИИ-помощнику по 1С и методике

## Архитектура

```
Телефон (PWA, GitHub Pages)
   │ fetch, CORS
   ▼
CORS-шлюз (FastAPI) ── публичный https-туннель
   │ Basic, GET-с-телом (стиль plpk)
   ▼
Публикация 1С softfontest · HTTP-сервис /hs/plpk/*  (данные + AiProxy → ИИ-бэкенд)
```

- Адрес шлюза приложение берёт из `api.json` (режим «Авто» в настройках) — при смене
  туннеля файл обновляется автоматически, приложение подхватывает новый адрес само.
- Учётные данные клиента хранятся только на телефоне (localStorage) и передаются
  напрямую сервису поддержки; шлюз их не сохраняет.
- Прод-вариант без туннеля: выдать CORS прямо на nginx `web.inter-soft.ru`
  (сниппет в `nginx-cors.md`), в настройках приложения указать адрес публикации.
